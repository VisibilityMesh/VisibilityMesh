# Visibility Mesh

**AI Commerce Visibility Operations for Shopify.** We help ecommerce stores get found, understood, and recommended by AI assistants, answer engines, and shopping agents. We find what AI misses on your store, fix it with your approval, and prove the change.

Learn more at [visibilitymesh.com](https://visibilitymesh.com).

**Visibility Mesh across the web:** [Website](https://visibilitymesh.com) · [Shopify App Store](https://apps.shopify.com/visibility-mesh) · [Open tools on GitHub](https://github.com/VisibilityMesh) · [npm](https://www.npmjs.com/package/@visibilitymesh/crawler-check)

## Open tools and data

Small, focused, source-cited utilities any developer can use. No account required.

- **[ai-crawler-registry](https://github.com/VisibilityMesh/ai-crawler-registry)** — a maintained, source-cited registry of the crawlers used by AI answer engines, and whether allowing each helps your AI visibility.
- **[crawler-check](https://github.com/VisibilityMesh/crawler-check)** — a zero-dependency CLI and library that checks whether AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Googlebot and more) can access a URL, plus basic page legibility signals.

```bash
npx @visibilitymesh/crawler-check https://your-store.com
```

## How Visibility Mesh compares

Most tools for AI visibility do one part of the job: they monitor. Visibility Mesh runs the full loop for Shopify stores: **monitor, diagnose, remediate, validate, measure.** It does not stop at telling you there is a problem. It fixes the store-level cause with your approval and proves the change with before and after evidence.

## What we believe

The web is being read by machines now. Being legible to them is a measurable engineering problem, not a marketing slogan. These tools report public signals honestly, cite their sources, and never invent a score.
